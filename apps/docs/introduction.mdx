## Whenever you need to prove something onchain — *identity, action, ownership, or permission* — you don't need to write a new smart contract or spin up a ZK system.

Signet is a **permissionless attestation protocol**: anyone registers a schema, anyone
issues cryptographically-verifiable claims ("attestations") about a subject, and any
application can read and trust them with no API key and no middleman.

<Tip>
Think of it like SSL for blockchains — a lightweight trust signal you can apply anywhere.
</Tip>

## Live on Monad, originally built on Stellar

Signet's primary deployment is on **Monad** (EVM, testnet chain `10143`), where it also
ships a Monad-native primitive: **proof of personhood from a device passkey**, verified
entirely on chain through the RIP-7212 P-256 precompile — no seed phrase, no wallet
required. The original implementation on **Stellar** (Soroban) is still live and
maintained.

## An Open Standard for Trust

Using our **Attestation Service** you get an open standard for verifying *statements,
transactions, and authorities* — identity proofs **on the blockchain**, with no contracts
to write, no infrastructure to run, and no ZK black magic required.

## Who is this for?

### Attestation Issuers

KYC providers, event organizers, DAOs, and certification bodies who want to:

- Issue verifiable credentials on-chain
- Enable other apps to verify your attestations
- Build reputation without siloed databases

### Verifiers

Applications that need to:

- Check if a user has valid KYC from any trusted provider
- Gate access based on credentials without vendor lock-in
- Query attestations from multiple issuers in one place

### Developers

Teams building:

- Reputation systems using aggregated attestation data
- Credential verification into existing dApps
- Multi-source identity checks

## Key Features

| Feature              | Description                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| **Schemas**           | Register a reusable claim definition; the registrant becomes its authority — permissionless. |
| **Resolvers**         | Optional contract that defines who can attest — fees, allowlists, rewards, custom rules.        |
| **Delegation**        | Sign attestations off-chain, submit on-chain — the submitter pays gas, not the attester. EIP-712 on Monad, BLS on Stellar. |
| **Passkey personhood**| Prove a real device holder from a WebAuthn passkey — no wallet, no seed phrase (Monad).         |
| **Multi-Chain**       | Monad (primary, EVM) + Stellar (original, Soroban) — Solana, Starknet, and Sui in development.  |
| **Revocable**         | Invalidate attestations when credentials expire or are revoked                                   |
