Signet runs on two chains today. Pick the one you're building on — the concepts
(schemas, attestations, resolvers, delegation) are the same on both; only the SDK
and signature scheme differ.

<CardGroup cols={2}>
  <Card title="Monad" icon="rocket" href="/monad/quickstart">
    **Primary chain.** EVM, viem-based `@signetprotocol/evm-sdk`, live on testnet
    (chain `10143`). Ships passkey proof-of-personhood.
  </Card>
  <Card title="Stellar" icon="star" href="/stellar/getting-started">
    **Original implementation.** Soroban, `@signetprotocol/stellar-sdk`, BLS delegation.
  </Card>
</CardGroup>

Not sure which one? Start with **Monad** — it's the actively developed chain and has
the simpler setup (a viem wallet, no keypair/XDR handling).
