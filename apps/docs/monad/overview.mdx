Signet on **Monad** is a Solidity port of the same attestation model that runs on
Stellar — permissionless schemas, direct and delegated attestations, pluggable
resolvers — plus one Monad-native primitive: **proof of personhood from a device
passkey**, verified on chain through the RIP-7212 P-256 precompile.

## The model

- **Schema** — a reusable definition string. Anyone can register one; the
  registrant becomes its `authority`. UID is deterministic:
  `keccak256(abi.encode(SCHEMA_DOMAIN, keccak256(definition), authority, resolver, revocable))`.
- **Attestation** — a signed claim structured by a schema.
  `(schemaUID, subject, nonce)` is unique per attester; the global `uid` binds the
  registry address and attester so it can't collide across deployments.
- **Resolver** — an optional contract the registry calls on every attest / revoke.
  `onAttest` / `onRevoke` are hard gates (a `false` return or a revert blocks the
  op); `onResolve` is a best-effort post-hook.
- **Delegation** — an attester signs an EIP-712 `Attest` / `Revoke` message
  off-chain; anyone submits it and pays gas.

## What's different from Stellar

| | Stellar (Soroban) | Monad (EVM) |
| --- | --- | --- |
| attestation `value` | `String` | `bytes` (schema-encoded) |
| delegated signatures | BLS12-381 | EIP-712 ECDSA (`secp256k1`) |
| personhood | — | WebAuthn / P-256 via RIP-7212 |

Everything else — field names, event shape, UID inputs, error set — is kept 1:1 so
the SDK, indexer, and docs stay chain-agnostic.

## Design stance

No admin, no upgrade path. The registries are immutable; all policy (fees, gating,
one-per-human rules) lives in resolver contracts that anyone can deploy and any
schema can point at. Reading and referencing an attestation needs no permission
and no API key.
